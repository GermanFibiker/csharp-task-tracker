# C# Task Tracker

Консольное приложение для управления списком задач.

## Возможности

- 📋 Просмотр списка задач
- ➕ Добавление новой задачи
- ❌ Удаление задачи
- 🔁 Бесконечный цикл работы программы
- ✅ Проверка корректности ввода

## Технологии

- C#
- .NET
- Console Application

## Чему научился

- Использовать `List<string>`
- Работать с `switch`
- Использовать циклы `while`
- Проверять ввод через `int.TryParse`

## Статус

Учебный проект.
